# Rust runtime assets

Generated by `scripts/prepare-rust.cjs` from the existing `assets/runtime` assets. The source artwork and audio attribution in `assets/runtime/SOURCES.md` remains applicable.

- PNG layers contain the runtime artwork with transparent margins cropped at build time. `layout.rs` retains each layer's original design coordinates, with two transparent pixels of sampling padding. `shoulder-cover.png` is exported from the accepted JavaScript rig at 960×640 and retains its feathered shoulder blend.
- WAV files are the same clips converted at build time to 24 kHz mono PCM, with the existing volume levels applied. The four voice clips retain their original names.
- `laugh-packed.mp4` is derived from the accepted transparent `assets/runtime/laugh.webm`: 448×576 color and grayscale alpha are stored side by side as 896×576 H.264 / 24 fps. Audio is in `laugh.wav`. Rust uses Windows Media Foundation to decode individual frames and recombine alpha.
- FFmpeg and Electron are build-time tools only. Neither is bundled or launched by the Rust executable. All prepared runtime assets are embedded using `include_bytes!`.
