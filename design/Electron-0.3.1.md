# MilkFrog DesktopPet 奶蛙桌宠

这是一个 Windows 奶蛙桌宠，灵感来自 BongoCat。奶蛙会操作朝向自己的七键键盘，手臂和眼珠随鼠标移动，也支持音效、装扮菜单和大小调整。

<img width="540" alt="奶蛙与朝向自己的七键键盘" src="assets/seven-key/preview.png" />

Windows 10/11 x64；普通用户无需安装 Node.js。下载后先退出旧桌宠，再启动新版本。

[点击下载 o(*￣▽￣*)ブ 最新版本](../../releases/latest)

普通用户只需要下载 Release 里的 Windows exe 文件即可使用

## 功能

- 透明背景、无边框、置顶桌宠窗口
- 全局鼠标位置检测，让眼珠轻微追随鼠标
- 仅响应 A / W / S / D / 左 Shift / 左 Ctrl / 空格，支持按住和组合键，其他键不触发动作
- 七键键盘朝向奶蛙，空格一侧靠近奶蛙，W 一侧靠近屏幕前方
- 每个键有独立按下反馈，手臂伸向最近按下的键；松开后回到仍按住的键或待机位置
- 鼠标、鼠标侧手臂和眼珠平滑跟随全局光标，支持左右键按下反馈
- 键盘与鼠标可同时响应；没有输入变化且动作结束时停止重绘
- 右键菜单切换装扮
- 大小范围 15%～135%，默认 65%；右键“大小”提供常用比例和每次 5% 的微调
- 奶蛙右键只保留装扮、动作、大小；使用系统原生菜单，缩小奶蛙不会把菜单裁切
- 静音开关
- 游戏模式：鼠标穿透、不抢焦点；从系统托盘右键菜单开关，音频仍由独立静音开关控制
- 开机自启动开关：从系统托盘右键菜单设置，默认关闭
- 捧腹大笑：播放透明背景的大笑动画与配套笑声，结束自动恢复；再次选择、单击奶蛙或按 Esc 可停止
- 切换、取消眼罩 / 生气 / 猫咪装扮时，从四条指定语音中随机播放一条；清除已有装扮也播放，重复加载设置不播放
- 系统托盘可显示、隐藏、静音或退出桌宠；隐藏时停止播放及全局输入监测
- 离线运行

## 隐私说明

程序只检测输入状态：

- 键盘：仅检测 A / W / S / D / 左 Shift / 左 Ctrl / 空格的按下与松开状态
- 鼠标：检测鼠标位置和鼠标按键状态

程序不会读取、保存或上传你输入的文字内容，也不会记录键盘日志，不会截图，不会发送网络请求。

更详细说明见 [PRIVACY.md](./PRIVACY.md)。

## 开发运行

```bash
npm install
npm start
```

依赖安装完成后，也可双击根目录的 `start.bat` 启动。

开发机需有 Windows 自带的 .NET Framework 4.x C# 编译器。启动和打包命令会先编译轻量输入助手；发行版自带助手，不会在运行时启动 PowerShell 或编译代码。

输入与动作几何检查：`node tests/input-state.test.js`。

输入助手退出检查：`node tests/input-helper.test.cjs`。首次检查前执行 `npm run build:input`。

自启动路径与状态检查：`node tests/startup.test.cjs`，使用模拟注册接口，不改系统启动项。菜单、尺寸上下限与托盘动作检查：`node tests/menu.test.cjs`。

隐藏 Electron 渲染检查：`npm run test:smoke`。检查结果及不同键位、背景和尺寸的截图保存在 `.test-artifacts/seven-key/`；该检查使用模拟输入，不代替真实键鼠、权限或游戏中的验收。

当前动画使用独立底图、两条手臂和鼠标进行二维分层变形，组合键全部保留按下反馈，键盘侧一只手伸向最近按下的键。素材制作记录见 [design/seven-key-v1](./design/seven-key-v1/制作说明与提示词.md)。

## 打包

```bash
npm run build
```

打包结果会输出到：

```text
dist/
```

- `MilkFrog-0.3.1-portable-x64.exe`：免安装，单文件双击启动；运行时临时解压内置运行环境。
- `MilkFrog-0.3.1-setup-x64.exe`：当前用户安装版，可创建桌面与开始菜单快捷方式。

两个版本都不要求管理员权限。当前构建未配置代码签名证书，Windows 可能显示未知发布者提示。构建目录的 `win-unpacked` 为展开后的运行环境，无需随免安装 EXE 一起分发。源码、测试、设计原图和未使用的旧动画不包含在发行包中。

自启动通过 Electron 的[系统启动项接口](https://www.electronjs.org/docs/latest/api/app#appsetloginitemsettingssettings-macos-windows)设置，只在用户操作开关时修改。安装版登记安装后的 EXE，免安装版登记外层 EXE，不登记临时解压路径；请先把免安装 EXE 放在固定位置，移动或改名后重新启用。Windows“启动应用”中禁用后不会被程序启动时自动恢复。安装版手动卸载时清理本应用的启动项，升级时保留。

## 与游戏一起使用

从系统托盘右键菜单开启“游戏模式”，之后也可从托盘操作装扮、动作和大小。建议使用游戏自身的窗口化 / 无边框窗口模式；独占全屏下普通桌面置顶窗口可能不可见。

鼠标跟踪读取的是 Windows 系统光标位置。FPS 游戏如果持续把光标锁在屏幕中央，鼠标动画可能停在中间或出现回位；本版本没有接入相对鼠标位移，也不会读取游戏内部输入数据。

应用只通过 Windows 官方接口查询按键状态和系统光标，不安装输入钩子或驱动，不注入游戏、不访问游戏进程内存、不合成输入，也不要求提升权限。反作弊或系统权限若阻止读取，接受读取失败，不尝试绕过。

这些措施不能证明获得了游戏或反作弊厂商的许可，也不能保证 Apex 等游戏一定兼容或不会误判。尚未进行 Apex 联机实测；如游戏提示不兼容或拦截，应退出桌宠。EA 的规则和反作弊策略以[官方规则](https://help.ea.com/en/articles/apex-legends/play-by-the-rules/)及[反作弊公告](https://www.ea.com/games/apex-legends/apex-legends/news/javelin-anticheat-announcement)为准。

## 技术说明

本项目使用 Electron 开发。Windows 全局输入检测使用随程序打包的 `MilkFrog.Input.exe`，以 28ms 间隔调用 `user32.dll` 的 `GetAsyncKeyState`；鼠标位置由 Electron 每 33ms 查询，仅变化时向渲染端发送。

运行时使用软件绘制，动画最多约 30fps，静止后停止重绘。画布缓存跟随窗口像素大小分配，常用图层缩小到 960×640，装扮与音频按需加载；不预加载全套原始图片。原始素材留在源码目录，未覆盖。

0.3.0 使用构建时压缩的 960×640 无损 WebP，切换装扮会释放上一个装扮位图。短音效复用播放器并在结束时卸载；大笑使用裁剪、抠绿和缩小后的 VP9 透明视频，按需解码，不实时逐像素抠图。播放视频时暂停桌宠画布动画，结束或取消后释放视频源并恢复键鼠动画。游戏模式允许音频，静音开关可关闭所有声音；静音不停止大笑画面。

运行媒体已保存在 `assets/runtime`，不依赖另一仓库的绝对路径。需要重做媒体时，开发机安装 FFmpeg 后执行 `npm run prepare:media`，默认读取相邻 `naiwa-pet/naiwa`；源图、原视频和原音频不覆盖。FFmpeg 只用于构建，不随发行包分发。打包只保留中文和英文运行环境语言包。

当前功能检查、媒体优化及内存短测见 [0.3.0 验证](design/0.3.0验证.md)，早期优化前后记录见 [内存与打包验证](design/内存与打包验证.md)。Electron 仍有多进程基础开销，实际内存会随窗口尺寸、系统缩放、音频播放和运行时长变化。
