## 实现与功能

运行代码全部为 Rust。Win32 分层窗口、托盘、系统菜单、注册表自启动；tiny-skia 软件绘制；Windows waveOut 音频；Media Foundation H.264 按帧解码。EXE 依赖检查只发现 Windows 系统 DLL，没有 Chromium / WebView、Node、独立输入助手、FFmpeg 或额外 VC++ 运行库 DLL。

沿用原形象、1536×1024 设计坐标、手臂分条变形、肩部羽化遮罩、七键布局、鼠标垫约束和已确认的方向 / 范围。七键与鼠标轮询并入主进程，隐藏时停表，静止后停止重绘。仅保存当前装扮。位图在构建时裁掉透明留白，并记录原坐标；边缘保留两像素采样余量。运行时复用画布、手臂缓冲和分层窗口位图。

奶蛙菜单仍只有装扮、动作、大小。范围 15%～135%，默认 65%，5% 微调；系统控制在托盘。大笑音画、四条随机装扮语音、静音、自启动、游戏模式与隐藏 / 显示均已迁移。大笑播放中取消静音会从当前视频时间恢复音轨。

声音构建时转为 24 kHz 单声道 PCM；音量系数沿用原版。大笑采用颜色与透明度并排的紧凑 H.264，逐帧恢复透明画面，不缓存完整视频。播放结束 / 中止 / 隐藏均释放解码器和音频设备。媒体与图片全部嵌入 EXE，视频仅在本地用户目录按需解出。

## 最终成品内存短测

隐藏窗口的画布与分层窗口位图为 624×416。只有 1 个 Rust 应用进程。通过 `GetProcessMemoryInfo` 读取本进程数据；输入通过程序内部状态模拟，不向系统合成键鼠。实际调用 Windows 音频设备、解码完整大笑视频，然后释放。测试未修改系统启动项。

| 场景 | 工作集 MiB | 私有内存 MiB |
| --- | ---: | ---: |
| 启动待机 | 22.46 | 10.22 |
| 键鼠持续活动并播放音效 | 27.02 | 11.20 |
| 大笑播放中 | 94.85 | 73.94 |
| 播放结束后 | 38.34 | 15.63 |
| 多次缩放后恢复默认大小 | 38.83 | 13.31 |

持续移动测试的 CPU 时间约为单个逻辑核心的 20.3%；本机报告 16 个逻辑处理器，按全机口径折算约 1.3%。这是短时间持续动画采样，非任务管理器现场读数，也不包含长时间游戏负载。静止时停止绘图。

同机还运行了原 Electron 0.3.1 的对照采样，存于 `.test-artifacts/performance-v0.3.1-rust-comparison.json`。其截图快照画布为 624×416，但测试末尾窗口边界发生了变化，且 Electron 工作集多进程求和会重复计算共享页，因此不把两次短测计算为严格的降幅百分比。两种架构的确切长期差异需要在相同可见窗口、系统缩放和使用顺序下继续观测。

这些数值不保证其他电脑、DPI、尺寸、媒体解码器与长时间运行都一致。大笑首次播放会加载 Windows 媒体 DLL，结束后其工作集不一定完全回到冷启动状态。
