# 0.3.1 尺寸与右键菜单修复

日期：2026-10-22。此次只调整尺寸下限及菜单组织，未修改奶蛙素材、手臂变形、鼠标方向 / 范围及按键白名单。

- 最小比例从 35% 降为 15%（144×96），最大仍为 135%（1296×864），默认仍为 65%。大小提供常用比例和每次 5% 的微调，达到上下限后禁用对应按钮。
- 原菜单绘制在桌宠 HTML 窗口内，缩小后会被操作系统窗口边界裁切。改用 Electron 系统原生 `Menu.popup`，不再把菜单放进奶蛙画布窗口；没有增加第二个常驻设置窗口或渲染进程。
- 奶蛙右键只保留装扮、动作、大小三组。开机自启动、隐藏 / 显示、静音、游戏模式、退出仅在系统托盘菜单显示。托盘也可操作装扮、动作和大小，方便鼠标穿透模式下使用。
- 清除装扮与随机语音行为保留；大笑时动作菜单显示停止大笑。隐藏会停止播放及输入助手，显示后恢复监测。

检查结果：

- 输入状态、原几何与自启动路径检查、输入助手退出检查通过。
- 隐藏 Electron 渲染检查通过：七键 / 组合键、鼠标跟随、装扮缓存、四条随机语音、游戏模式音频、静音、大笑播放 / 恢复，以及 144×96、336×224、624×416、1296×864 的实际视口和画布尺寸。渲染错误为空。
- 已查看 15% 与 65% 的画布导出截图，整体形象正常。尺寸截图位于忽略的 `.test-artifacts/seven-key/size-*.png`，常用尺寸预览更新到 `seven-key-v1/runtime-preview.png`。
