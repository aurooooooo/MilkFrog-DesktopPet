# 内存优化与 Windows 打包验证

整理日期：2026-10-22。内存短测在 2026-10-21 完成；0.2.1 的手臂比例调整在 2026-10-22 完成。

本页为 0.2.x 历史记录；0.3.0 已增加自启动、语音和视频，并按用户补充取消游戏模式自动静音，见 `0.3.0验证.md`。

## 已实施

- 常驻 PowerShell 脚本改为随包分发的 `MilkFrog.Input.exe`，运行时不编译、不启动 PowerShell。仅以 28ms 间隔查询七键与鼠标左右键的当前状态，父进程输入管道关闭后自动结束。
- 画布与两条手臂缓存按实际窗口像素尺寸分配，不固定分配 1536×1024；常用图片在加载时生成 960×640 位图。装扮和音频按需加载，加载完成后释放启动占位图引用。
- 使用软件绘制，动画约 30fps，动作结束停止重绘，系统光标不变时不发送重复 IPC；最小化或暂停时停止输入助手。
- 增加托盘与游戏模式：点击穿透、不抢焦点、静音、普通桌面置顶。不开启游戏内注入，不要求管理员权限。
- 发行包只包含运行必需的源码、素材和输入助手，不含设计记录、测试、旧动画、开发依赖。

## 本机内存短测

测量脚本：`tests/runtime-profile.cjs`。Electron 31.7.7，隐藏窗口，启动约 8 秒后取待机快照，再模拟约 6 秒光标移动。优化后的测试关闭了隐藏窗口的背景节流，使隐藏测试仍可绘制。测试目录设置中的缩放为 0.35；早期基线没有单独记录窗口边界。两次测量为单次短测，适合判断改善方向，不构成严格、长期的性能基准。

| 口径 | 优化前 MiB | 优化后 MiB |
| --- | ---: | ---: |
| 待机：各进程工作集合计，含输入助手 | 625.1 | 359.3 |
| 模拟鼠标移动：各进程工作集合计，含输入助手 | 588.6 | 339.3 |
| 模拟鼠标移动：各进程私有字节合计，含输入助手 | 513.6 | 197.1 |
| 输入助手工作集 | 84.2 | 14.7 |

工作集求和会重复计算进程间共享页，与任务管理器的某些内存列口径不同。窗口大小、DPI、音频首次播放、装扮、显卡驱动、运行时长均会影响结果。0.2.1 仅更换两侧手臂素材，没有重新测量上述数字；不能将它们当成所有机器或 Apex 运行期间的固定占用。

原始快照保存于 `performance/baseline.json`、`performance/optimized.json`。

## 验证与边界

- 输入状态、七键组合、鼠标方向、手臂位置和编译后输入助手白名单检查通过。
- 输入助手生命周期检查通过：父进程管道关闭后结束。
- 隐藏 Electron 渲染检查通过：七键、键鼠组合、释放恢复、装扮按需加载、游戏模式切换、菜单边界及窗口缩小；无渲染错误。静止、W 按下与鼠标移动截图已人工查看，0.2.1 修平键盘侧肩部、收细鼠标侧前臂。
- 游戏模式的焦点与鼠标穿透设置在主进程测试中检查通过。
- 0.2.1 免安装 EXE（77,004,787 字节）和当前用户安装 EXE（77,335,201 字节）构建成功，打包源码与两侧新手臂素材均逐文件核对一致。可执行文件校验和位于 `dist/SHA256SUMS-0.2.1.txt`。
- 0.2.0 单文件启动测试在较短等待时间内未检测到输入助手，后续延长等待的复测未执行；0.2.1 未再启动成品 EXE，不能报告 EXE 端到端启动验收通过。
- 未进行安装程序安装 / 卸载验收、Apex 联机或反作弊兼容性验收；未执行提交、推送或发布 Release。程序未配置代码签名证书。
