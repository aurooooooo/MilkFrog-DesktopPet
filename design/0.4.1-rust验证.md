# 0.4.1 按键静音与清除装扮音效

日期：2026-10-22。

## 变更

- A / W / S / D / 左 Shift / 左 Ctrl / 空格仅更新动画，不创建或播放按键音频。原键盘独立播放器已移除。
- “清除装扮”在确实清除已有装扮时播放原来的按键音；切换或取消眼罩 / 生气 / 猫咪仍播放指定的随机语音。
- 所有声音继续遵守静音设置，游戏模式不自动静音。形象、布局、手臂运动、大小范围与安装流程保持原样。

## 检查

- Rust 4 项单元检查、Clippy 通过。
- 对最终 0.4.1 单文件执行完整隐藏检查并通过，结果见 `rust-v0.4.1/runtime-result.json`。
- 检查复用了生产按键更新函数：逐个按下、松开七键及连续键鼠活动时，音频通道保持空闲。
- 清除装扮后核对音频源的实际字节，确认等于原 `keyboard-tap.wav`，并实际打开 Windows 音频设备；测试提交静音 PCM，不做现场听感验收。
- 原有透明视频完整播放、再次选择 / Esc 停止、装扮语音、游戏模式、静音及恢复、尺寸上下限、设置读写和窗口消息检查均通过。连续缩放 GDI 对象保持 12 → 12。
- 624×416 本机短测工作集：待机约 22.51 MiB、键鼠活动约 22.71 MiB、大笑中约 94.90 MiB、播放结束约 38.97 MiB。数值随环境变化，不代表长期无泄漏。
