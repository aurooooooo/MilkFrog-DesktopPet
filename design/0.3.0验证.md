# 0.3.0 功能与体积优化

日期：2026-10-22。

## 新功能

- 自启动默认关闭。菜单和托盘通过 Electron 的 Windows 启动项接口读取、设置当前用户启动项；不会仅凭本地设置文件自动恢复系统禁用的项目。
- 安装版使用安装后的 EXE，免安装版使用 `PORTABLE_EXECUTABLE_FILE` 指向的外层 EXE，避免注册临时解压目录。开发运行使用 Electron 加项目路径。安装版手动卸载清理对应项，升级保留。
- 右键 / 托盘选择捧腹大笑，在原窗口播放透明视频和配套笑声；结束恢复桌宠。再次选择、单击奶蛙、Esc、暂停桌宠或最小化可中止。播放时暂停画布动画；结束 / 中止卸载视频源。
- 切换、取消眼罩 / 生气 / 猫咪及清除已有装扮时随机播放指定四条语音之一，复用单个播放器，不叠加多个语音。初始化 / 读取设置不播放语音。
- 根据用户补充，游戏模式允许音频，不再自动静音。独立静音开关仍控制所有声音；静音时仍可播放无声大笑画面。

## 优化

- 原始大笑视频 7,573,310 字节，原音轨 145,876 字节。构建时去绿幕、去绿边、裁去多余背景，缩至 448×576 / 24fps，VP9 alpha + Opus；FFmpeg 不随程序分发，也不在程序运行时启动。
- 图层在构建时缩至实际运行使用的 960×640 并无损 WebP 编码，避免每次启动解码全尺寸 PNG。旧源图和原音视频未覆盖。
- 只保留当前装扮位图，切换 / 清除时关闭旧位图；音效结束立即卸载资源，视频结束移除来源并恢复桌宠。
- 发行包只保留中文和英文语言包，不包含原始 PNG、原始视频、其他旧素材、测试和设计文件。

媒体处理命令：`scripts/prepare-media.cjs`。来源记录：`assets/runtime/SOURCES.md`。

0.3.0 的免安装版和安装版均构建完成。免安装包由 0.2.1 的约 77.0 MB 降至约 67.0 MB，约缩小 13%，同时加入视频和四条语音。运行环境仅保留 `en-US.pak`、`zh-CN.pak`。打包后的代码与全部运行媒体逐文件核对一致，确认不含原始 PNG / MP4 和开发目录；最终视频离线解码复核了尺寸、透明背景与主体不透明。校验和保存于 `dist/SHA256SUMS-0.3.0.txt`。

## 内存短测

数据：`performance/v0.3.0.json`。同一次隐藏测试中先待机，再模拟键鼠并实际调用短音效，播放大笑约 2.5 秒，最后停止媒体约 1.5 秒。声音输出在测试窗口层静音，代码仍创建、播放和释放媒体源；没有修改开机自启动。

| 场景 | 工作集合计 MiB | 私有字节合计 MiB |
| --- | ---: | ---: |
| 待机 | 359.4 | 204.0 |
| 键鼠与短音效 | 433.8 | 207.6 |
| 大笑中 | 429.6 | 219.4 |
| 停止媒体后 | 417.8 | 210.7 |

均含约 14.6 MiB 的输入助手工作集；进程工作集求和会重复计算共享页。首次音频播放后 Chromium 音频服务可能驻留，释放媒体源不代表系统工作集立即回到启动水平。此轮增加了实际声音与视频场景，窗口大小 / 画布快照取于不同时间，不能与旧版单次短测作严格百分比比较，也不证明长期无泄漏。

未做真实重启后的自启动验收、安装 / 卸载验收、成品 EXE 端到端启动验收或 Apex 联机反作弊验收。仍未配置代码签名证书。
